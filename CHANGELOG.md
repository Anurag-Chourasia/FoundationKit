# Changelog

## 0.3.0

- Add `ByteCountFormatting` protocol and `ByteCountFormatterFactory` supporting configurable units, countStyle, and zero-size fallback.
- Add `RelativeDateFormatting` protocol and `RelativeDateTimeFormatterFactory` with `DateFormatterFactory.makeRelative(...)`.
- Add mandatory ecosystem architecture governance rules to `.swiftlint.yml`.
- Expand unit tests to 27 tests with >95% line coverage.

## 0.1.1 — release candidate

- Add MIT license and reproducible Xcode 27.0 / Swift 6.4 CI.
- Preserve all 0.1.0 public APIs and runtime behavior.
- Retain the existing 16 tests with strict concurrency and warnings as errors.

- Initial tagged foundation utilities.
